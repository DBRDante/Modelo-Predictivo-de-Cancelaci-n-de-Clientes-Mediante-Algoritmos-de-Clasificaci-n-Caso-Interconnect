# Modelo-Predictivo-de-Cancelaci-n-de-Clientes-Mediante-Algoritmos-de-Clasificaci-n-Caso-Interconnect
royecto de Ciencia de Datos para predecir la cancelación de clientes (churn) en Interconnect. Integra datos contractuales, demográficos y de servicios para entrenar un modelo XGBoost con un desempeño sobresaliente: AUC-ROC de 0.9285 y 89.43% de exactitud (Puntuación SP: 6.0).
